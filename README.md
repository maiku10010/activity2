# Information Technology Infographic

## Project Description

This project is a two-page infographic created using Canva to demonstrate effective documentation and visual communication through hierarchy, layout, icons, color, and typography.

## Page 1: Impact on Society

The first page presents the impact of Information Technology on society. It highlights how IT has influenced different areas, including:

* Communication
* Education
* Employment and Business
* Healthcare
* Government and Public Services
* Challenges such as cybersecurity, privacy, misinformation, and the digital divide

The infographic emphasizes how technology provides opportunities for society while also creating challenges that require responsible and ethical use.

## Page 2: College Course Comparison

The second page presents a graphical comparison of students taking different college courses.

| College Course             | Percentage |
| -------------------------- | ---------: |
| BS Computer Science        |        40% |
| BS Information Technology  |        30% |
| BS Information Systems     |        18% |
| BS Electronics Engineering |        12% |

A graphical chart is used to make the percentage comparison easier to understand.

## Tools Used

* Canva
* GitHub
* Markdown

## Learning Objective

This activity demonstrates the use of visual communication principles to organize information clearly and effectively. It also provides experience in documenting and presenting a completed project using GitHub.
